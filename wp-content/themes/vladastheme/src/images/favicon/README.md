# Luxor favicon

Izveden iz slova L originalnog `../logo.png`; original nije menjan. Belo slovo na tamnoplavoj podlozi #0a1225. Deterministički izrez i promena boje, bez AI generisanja.

- favicon.ico: 16, 32 i 48 px.
- PNG: 16, 32, 96, 180, 192 i 512 px.
- site-icon-512.png može se izabrati kao WordPress Site Icon.

Header koristi ove fajlove samo ako WordPress Site Icon nije već postavljen. Manifest koristi relativne putanje. Nema promena deployment konfiguracije ni automatskog objavljivanja.
